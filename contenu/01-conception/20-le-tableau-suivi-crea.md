# Le tableau Suivi Crea, l'interface entre Adrien et Claude

> Tout passe par ce classeur. Adrien y écrit ce qu'il veut, Claude y lit ce qu'il doit
> faire et y écrit ce qu'il a fait. Il n'y a pas d'autre canal de commande.

## Ce que le tableau décide sans avoir à le dire

**L'onglet dit pour quelle page de vente on écrit.** Le classeur est découpé par
funnel : une ligne posée dans l'onglet du funnel 2 donne un script pour la VSL 2, avec
son porte-parole et son tutoiement. Personne n'a à le préciser.

Cela ne change rien à la règle de fond : **aucune VSL n'est réservée à un avatar.** Les
quatre avatars peuvent apparaître dans les trois onglets, et c'est voulu — ce sont des
combinaisons qu'on veut pouvoir tester.

## Ce que la couleur dit

**Le statut d'une créa n'est pas écrit : il est porté par la couleur de fond de sa
cellule.** La légende vit en colonne A de chaque onglet, et elle est relue à chaque
fois — changer une couleur dans le classeur ne demande de modifier aucun script.

| Couleur | Ce que ça veut dire |
|---|---|
| **violet** | winneuse — c'est elle qu'on itère le mois prochain |
| **jaune** | script à écrire |
| **bleu** | script écrit, créa à produire |
| **vert** | créa terminée, montage final à faire |
| **orange** | prête à être lancée |
| **blanc** | en ligne |
| **rouge** | coupée |

## Ce que la colonne Format porte vraiment

Le format n'est pas qu'un genre : il porte aussi **la technologie de production**,
entre parenthèses à la fin — `UGC AI femme 50 ans (Argil)`, `Static (Canva)`,
`Interview podcast (tournage réel)`.

Écrire « tournage réel » plutôt que de laisser vide. **L'absence d'information ne doit
jamais signifier quelque chose** : un blanc veut dire « personne n'a rempli », pas
« c'est du tournage ».

| Concevoir les variations, remplir Itération / Format / Angle / Avatar | ● | |
| Poser les dates de lancement | ● | |
| Écrire les scripts et les AdCopy | | ● |
| Faire avancer la couleur au fil de la production | | ● |
| Valider chaque étape | ● | |

Claude écrit dans le classeur sans demander l'autorisation — une demande en attente
immobiliserait le travail pendant une absence. En échange, deux réflexes tiennent lieu
de garde-fou : **vérifier qu'une plage est bien vide avant d'y écrire**, et **dire
précisément ce qui a été écrit et où** après chaque passage.
