# Mise en forme des documents

> Comment se présente un fichier déposé dans le Drive. Le fond est jugé à la
> relecture ; la forme, elle, ne se discute pas : elle est identique d'un document
> à l'autre pour qu'Adrien n'ait jamais à chercher où regarder.

## Le nommage

| | |
|---|---|
| Le document | `AdsCopy {numéro}` — par exemple `AdsCopy 136` |
| Son dossier au Drive | `Ads {numéro}` — par exemple `Ads 136` |
| Les vidéos livrées | `Ads {numéro} {format}.mp4` — `Ads 136 9x16.mp4` |
| Le classeur de suivi | **« Suivi Crea Meta ADS NarratiFluent »** |

Un dépôt **remplace** le fichier de même nom au lieu d'en créer un second : le lien
de partage et l'historique sont conservés, et personne n'a à deviner lequel des deux
est le bon.

## La typographie

- **Corps du texte** : Nunito demi-gras, pour tout le document.
- **Indications de production** — didascalies, notes de tournage, consignes de
  montage : **surlignées en jaune, texte en noir**. Jamais en gras seul, jamais en
  couleur de texte : c'est le surlignage qui les distingue du texte dit.
- Le **texte dit** reste nu : c'est ce qui sera prononcé, rien d'autre.

**Pourquoi le surlignage plutôt que le gras.** Un script se lit en diagonale pour
vérifier ce qui est prononcé. Le gras se confond avec les mots qu'on veut appuyer
dans la diction ; le surlignage, non — on voit d'un coup d'œil ce qui est une
instruction et ce qui est une réplique.

## Ce que contient un fichier AdsCopy

Un fichier par ads, dans cet ordre :

1. **Le script vidéo**, avec ses indications de production surlignées.
2. **Le jeu d'AdCopy de l'avatar**, repris tel quel.
3. **Les Headlines de l'avatar**, reprises telles quelles.
4. **La Description.**
5. **Le bloc d'auto-contrôle** — le résultat de la Copy Ads Checklist.

Les trois déclinaisons de VSL figurent dans le même document quand l'ads est écrite
pour plusieurs funnels.
